# F32 ArgmaxPool 候选

此案正在建立证明，尚未完整验证，不计入 verified。原始身份见 `proof/originals.json`，原件、两侧精确补丁和反例分别保留。

两侧原版都把正的 `size_t pooling_elements` 转为 `int`，大于等于 2^31 时可能跳过整个池化过程。修复保留无符号 64 位计数，并将最后不足 9 项后的剩余数置零，以避免无符号减法回绕。保留原始严格大于比较、首次最大值的并列选择、NaN 和符号零行为、32 位索引回绕及原始循环与向量操作顺序。

将验证公开完整尺寸域与实际内存条件下的 C-shim 部分正确性，允许间接表中的输入指针重复或别名；两侧输出和索引分别拥有。有限原生检查只提供补充证据，不代替实际 C body、完整接口、全新 Coq 依赖闭包及最终假设审计。真实 ISA 对应、物理 ABI 和完整终止性尚未证明。

证明用普通 C 重构：每处 `*id++` 改为 `ap_read_table(id++)`；该 helper 实际只执行一次 `return *p`，两项实际 C 义务与严格 typed 接口已通过。它用于复用同一指针表资源，不属于 intrinsic spec 豁免。最初 unsigned-count 补丁、原 native 证据及新补丁均保留在 repair/history 中。修改后 native 回归单独重跑；整案仍未通过。
